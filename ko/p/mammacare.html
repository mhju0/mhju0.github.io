Mammacare

아기가 먹은 음식과 알레르기 반응을 기록하고, 월령과 알레르기 기록을 고려한 AI 이유식 식단을 추천합니다. 새로운 재료를 하나씩 확인하는 알레르기 관찰 규칙도 식단에 반영합니다. 저는 팀장으로 백엔드의 인증, 식사 알림, AI 식단 생성 로직을 맡았습니다.

  • FastAPI
  • PostgreSQL
  • Azure OpenAI
  • React
  • FCM
아이 정보월령 · 알레르기 기록
후보 선정코드
식단 생성Azure OpenAI · JSON
규칙 검증코드
  1. 아이 정보

    아이의 월령과 지금까지의 알레르기 기록이 식단 생성의 입력입니다.

  2. 후보 선정

    프롬프트에 맡겼던 후보 선정과 대체 구성을 코드로 옮겼습니다. 월령과 알레르기 기록에 따라 쓸 수 있는 재료를 먼저 거릅니다.

  3. 식단 생성

    Azure OpenAI를 JSON 형식 응답으로 호출합니다. 규칙만으로 정해지는 식단은 모델을 호출하지 않고 만듭니다.

  4. 규칙 검증

    모델이 돌려준 식단을 코드로 다시 확인합니다. DB에 없는 재료나 확정된 알레르기 재료가 들어 있으면 그 식단은 받지 않습니다.

모든 식단에 AI 호출이 필요할까?

아니요. 규칙만으로 정해지는 식단은 모델을 호출하지 않고 코드로 만들고, 모델이 만든 식단은 코드로 다시 검사합니다. 프롬프트에 맡겼던 후보 선정도 코드로 옮겼습니다.
