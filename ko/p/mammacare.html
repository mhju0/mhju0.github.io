웹 · AI · 팀 프로젝트 · 2026.05–2026.06

Mammacare

아기가 먹은 음식과 알레르기 반응을 기록하고, 월령과 알레르기 기록을 고려한 AI 이유식 식단을 추천합니다. 새로운 재료를 하나씩 확인하는 알레르기 관찰 규칙도 식단에 반영합니다. 저는 팀장으로 백엔드의 인증, 식사 알림, AI 식단 생성 로직을 맡았습니다.

  • FastAPI
  • PostgreSQL
  • Azure OpenAI
  • React
  • FCM
  • 우수상아카데미 최종 발표 2위
  • 5인 팀팀장코드 검토와 병합

모든 식단에 AI 호출이 필요할까?

아니요. 규칙만으로 정해지는 식단은 모델을 호출하지 않고 코드로 만들고, 모델이 후보에 없는 재료를 돌려주면 승인된 후보로 바꿉니다. 프롬프트에 맡겼던 후보 선정도 코드로 옮겼습니다.

핵심

  • 5인 팀 팀장 · 코드 검토와 병합
  • 확정 알레르기 재료는 모델 호출 전에 후보에서 제외
  • JWT 인증과 Google·Kakao·Naver 로그인
  • 식사 알림에 중복 방지 키 적용

동작 흐름

  1. 아이 정보

    아이의 월령과 지금까지의 알레르기 기록이 식단 생성의 입력입니다.

  2. 후보 선정

    프롬프트에 맡겼던 후보 선정과 대체 구성을 코드로 옮겼습니다. 월령과 알레르기 기록에 따라 쓸 수 있는 재료를 먼저 거릅니다.

  3. 식단 생성

    Azure OpenAI를 JSON 형식 응답으로 호출합니다. 규칙만으로 정해지는 식단은 모델을 호출하지 않고 만듭니다.

  4. 결과 보정

    모델이 후보에 없는 재료를 돌려주면 승인된 후보로 바꿉니다. 확정된 알레르기 재료는 모델을 호출하기 전에 후보에서 이미 뺐습니다.
