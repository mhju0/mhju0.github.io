무한초성

초성 두 개가 주어지고, 60초 동안 그 초성에 맞는 두 글자 명사를 입력하는 iPhone 단어 게임입니다. 한 판이 끝나면 입력한 단어와 놓친 단어를 확인하고 바로 다음 판을 시작합니다. 인터넷이 없어도 할 수 있습니다.

  • Swift · SwiftUI
  • Java 21
  • Spring Boot
  • PostgreSQL
  • Docker
  • 54,349 뜻풀이를 갖춘 단어
  • V1–V4 Flyway 스키마 버전
  • 60초 한 판
한 판60초 · 오프라인
대기열기기에 저장
제출SHA-256 키
저장PostgreSQL · Flyway
  1. 한 판

    단어 목록을 앱에 넣어 인터넷 없이도 한 판을 할 수 있습니다. 게임 규칙은 별도 Swift 패키지로 분리해 시뮬레이터 없이 테스트합니다.

  2. 대기열

    보내지 못한 결과는 저장 파일에 쌓아 두었다가 연결되면 보냅니다.

  3. 제출

    서버는 결과 내용으로 SHA-256 키를 만듭니다. 같은 내용이 다시 오면 그대로 받고, 같은 판에 다른 내용이 오면 409로 거부합니다.

  4. 저장

    Spring Boot 4와 Java 21 서버가 PostgreSQL에 저장하고 스키마는 Flyway로 관리합니다. 요청은 클라이언트별 토큰 버킷으로 제한합니다.

TestFlight 베타이며 App Store에는 아직 출시하지 않았습니다.
