Allergy Tracker

An iPhone app I built on my own, based on our team project Mammacare. It focuses on logging a baby's food and reactions as they happen, so I dropped meal recommendations and other features, and it needs no login.

What changes without accounts or server sync?

Ingredient status is calculated from records, and observation rules are checked in code. With no server accounts or sync, records are stored only on the device.

Highlights

  • Ingredient status is not stored but calculated from records
  • A transaction check keeps observations to one at a time

How it works

  1. Start observation

    A new observation cannot start while another ingredient is being observed. This check runs in the same transaction as the save.

  2. Daily log

    If a record already exists for the day, the app returns it and does not create a new one.

  3. End observation

    The update carries a condition so that only an unfinished observation can be ended. If the state changed in the meantime, it reports an error.

  4. Status

    An ingredient's status is not stored; it is calculated from observation records each time. Reminders are also rebuilt from the stored records.

A recording tool, not a medical diagnosis or an allergy safety guarantee.
