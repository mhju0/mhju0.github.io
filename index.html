filing-digest GitHub ↗ 워크스루 ↗Walkthrough ↗

한국 DART와 미국 SEC 공시를 이중언어로 읽어주는 앱의 백엔드. 정확한 재무 수치는 LLM 바깥의 구조화 데이터 경로에 남깁니다. Backend for an app that reads Korean (DART) and US (SEC) filings in both languages, keeping exact financial figures on a structured-data path outside the LLM.

어려웠던 지점 — 가드가 프롬프트가 아니라 기계적입니다. 인용이 비었거나 출처를 특정할 수 없으면 서술 전체를 차단하고, 모델이 쓴 재무 수치 패턴은 정규식으로 막습니다. 둘 중 하나만 실패해도 서술은 버리고 구조화 수치는 남깁니다. 그게 실제로 되는지는 골든셋 24케이스를 실행 중인 API에 그대로 돌려 채점하는데, 최근 실행에서 24케이스를 모두 통과했고 검색은 Hit@1 0.900 · MRR 0.950이었습니다. The hard part — the guards are mechanical, not prompt-level. A missing or unresolvable citation rejects the entire narrative, and anchored financial figures written by the model are blocked by pattern; either failure discards the prose and keeps the structured numbers. Whether that actually holds is scored by running a 24-case golden set against the live API — the most recent run passed all 24, with retrieval at Hit@1 0.900 and MRR 0.950.

FastAPI · PostgreSQL 16 + pgvector (HNSW) · KURE-v1 · Upstage Solar · SwiftUI · Docker Compose

이동거리·휴식일·일정 밀도로 NBA 팀의 피로도를 점수화하고 경기 결과를 예측합니다. 1985-86 시즌까지 거슬러 27,400경기를 백테스트했습니다. Scores what the NBA schedule does to a team — travel, rest, density — and predicts results, backtested across 27,400 games to the 1985–86 season.

오늘비raintoday Live ↗ GitHub ↗

전국 강수 예보를 "오는지"가 아니라 "언제 오는지"로 답합니다. 기상청 관측지점마다 예보 성능을 따로 학습합니다. A nationwide rain forecast that answers when it rains, not just whether — learning forecast performance separately at each weather station.

어려웠던 지점 — 자기 학습을 언제 믿을지 정하는 것. 하루 두 번, 결과가 존재하기 전에 적응형과 균등 가중 예보를 지점마다 함께 얼려 저장하고, 동일한 집합에서 채점한 뒤, 적응형이 지는 날에는 학습을 스스로 정지시킵니다. The hard part — deciding when to trust its own learning. Twice a day it freezes both the adaptive and equal-weight blends at every station before the outcome exists, scores them on the identical set, and suspends learning on days the adaptive one loses.

TypeScript · Next.js 16 · React 19 · PostgreSQL · GitHub Actions · Vercel
